# Local Development

## Required Accounts

- Supabase project
- Expo account for push notification testing and EAS project ID

## Environment

Copy `.env.example` to `.env` and fill in the Supabase URL, Supabase anon key, and Expo EAS project ID.

## Commands

- `npm start`: start Expo.
- `npm test`: run tests.
- `npx supabase start`: start local Supabase if the Supabase CLI is installed.
